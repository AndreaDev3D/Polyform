Local-first

Your work is a folder.
That is the whole idea.

Open a project and there is nothing to log into and nothing syncing in the background. A Polyform project is a directory of ordinary files: a binary scene, a real SQLite undo journal, and your images stored by content hash. Back it up with cp. Diff it in git. Open it in ten years.

  • Undo that survives closing the app. Every edit is journaled to disk. Reopen a project a week later and keep pressing Ctrl+Z, or scrub the timeline and jump anywhere in its history.
  • No save button. Edits are written about a second after you stop making them, and the title bar tells you when they land.
  • A format you can read without us. The scene schema is published, and the bundle opens with standard tools.
MyPoster/ ├── MyPoster.poly the file you double-click ├── scene.bin the scene graph ├── history.sqlite undo, on disk ├── thumbnail.png preview └── assets/ deduplicated by hash └── e3b0c44298fc…855.png

Copying the folder copies the entire project — shapes, history and assets included. Design-system libraries are just other projects you attach.

The tools

A real editor, not a demo

Multi-page documents, frames with auto layout and constraints, components and instances, pen paths with a full vector-edit mode, text shaped from your system fonts, gradients, effects, masks, booleans, snapping and smart guides, SVG import, PNG and SVG export.

Pages, layers, components

Multi-page documents, nested frames with auto layout and constraints, and components whose instances carry journaled overrides you can swap or detach.

Gradients, effects & masks

Multi-stop gradients, drop and inner shadows, layer and background blur, all sixteen blend modes, arcs and rings, and group, even-odd and text masks.

The inspector you expect

Align and distribute, scrubbable numeric fields, per-corner radius, per-side strokes, shared styles, and the colours in your selection listed and editable in one place.

Under the hood

Built like an engine, not a page

Shapes are never DOM or SVG nodes. Everything paints through a GPU-composited canvas pipeline, behind a renderer interface with two peer backends.

100,000 shapes

panning at 60fps

A lyon-tessellated, batched WebGPU pipeline: 0.18 ms of CPU per frame, in one draw call, measured by the harness inside the app. Where there is no WebGPU device it falls back to Canvas2D on its own.

21 / 21 fixtures

pixel-identical across both renderers

Shadows, blurs, every blend mode, shaped text from a GPU glyph atlas and all three mask kinds are held to the Canvas2D reference, so turning the GPU on cannot change how your file looks.

Rust engine core

proven equivalent by differential fuzzing

Geometry, spatial index, exact-CSG booleans, the scene graph, constraints, layout, serialization and text shaping all have Rust twins compiled to WebAssembly. Each one ships only after a fuzz suite proves it matches the TypeScript reference.

Real text shaping

rustybuzz, not the browser

Kerning and ligatures come from the font's own tables, with layout pinned to the shipped engine rather than to whatever Chromium version you happen to have. Fonts are read straight off your OS.

Agents, on your terms

An MCP server inside the app lets an AI agent read the document you have open, see your canvas and make attributed, single-undo edits. Off by default, loopback-only, token-protected, and split into four capabilities you grant and revoke while it is connected.

A headless CLI

polyform new, query, export and mcp serve work on .poly files with no window at all — exports pixel-identical to the app, for CI and scripting.

Import from Figma experimental

Reads a .fig export offline into editable layers, and reports everything it approximated or dropped rather than losing it quietly.

Before you install — the honest part

  • This is a beta. Polyform is under active development and the feature matrix marks exactly what is finished, partial and planned.
  • The installers are not code signed yet. Windows SmartScreen and macOS Gatekeeper will warn you. Verify what you downloaded against the published SHA-256 checksums, or against the Sigstore build provenance attestation with gh attestation verify <file> --repo AndreaDev3D/Polyform.
  • It will not update itself. Polyform tells you when a new version exists and leaves the decision, and the download, to you.

Prefer to build it yourself? git clone, npm install, npm run dev — the README has the details.
